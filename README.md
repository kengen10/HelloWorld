## How to Run

1. Ensure Python is installed on your system (Python 3.6 or higher recommended).
2. Open a terminal or command prompt.
3. Navigate to the project directory:
   ```bash
   cd HelloWorld
   ```
4. Run the program:
   ```bash
   python hello_world.py
   ```
