# Overview

This software is an interactive Hello World console application that demonstrates core features of the Python programming language. It goes beyond a simple print statement to showcase variables, expressions, conditionals, loops, functions, classes, data structures (lists and dictionaries), and file input/output operations. The program presents a menu-driven interface with six distinct features: personalized greetings, a FizzBuzz counting game, multiplication table generation, a student profile management system, and file-based user data persistence.

The purpose of writing this software is to establish a solid foundation in Python syntax and object-oriented design while building a practical, functional application that can be extended in future modules. This project serves as the starting point for demonstrating proficiency in applied programming concepts throughout the CSE 310 course.

# Development Environment

Tools used to develop this software:
- **IDE:** Visual Studio Code with Python extension
- **Version Control:** Git and GitHub for source code management
- **Runtime:** Python 3.x interpreter on Windows operating system

Programming language and libraries:
- **Language:** Python 3.x (no external libraries required - uses only the Python Standard Library)
- **Built-in modules used:** `os` file I/O operations through `open()` context managers
